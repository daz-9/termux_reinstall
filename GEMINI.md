# GUI Design & Architecture Rules

All desktop GUI configs are generated by `configure.py` (`configure_x11()`) and packages by `setup.py` (`install_x11()`). **Always update `configure.py` first and run `python3 configure.py --x11`** rather than hand-editing files under `~/.config/` or `$PREFIX/bin/`.

## 2. Typography & Iconography

- **Font family:** `JetBrainsMono Nerd Font` everywhere (`monospace` fallback only).
  - Terminal: `19pt`
  - Polybar: `14pt` (vertical offset `;3`)
  - Rofi: `14`
  - Eww dock pills: `25–34px` icons, `24px` workspace digits, `13–14px` sublabels; popups: `26px` icons, `20px` bold labels.
- **Icon consistency & centering:**
  - Prefer **Material Design Nerd Font glyphs (`\U000f0...`)** for uniform square bounds (especially volume controls: `\U000f0415`, `\U000f057e`, `\U000f075f`, `\U000f0374`).
  - Because non-Mono `JetBrainsMono Nerd Font` gives Nerd Font glyphs a 1-cell logical advance in GTK/Pango, wide icons overflow right. Any wide glyph in Eww **must** declare an explicit `.nf-*` `padding-right` compensation in `eww.scss` and be pixel-checked on `:9` via `XGetImage` (target horizontal center within `±1px` of the pill center).
  - Every `box` holding centered text/digits inside fixed-width containers (`ws-pill`, etc.) must set `:hexpand true` + `:halign "center"`.

## 3. Geometry, Radii & Compositing

- **Radii scale:**
  - Windows (`picom.conf`): `corner-radius = 18`
  - Dock container: `24px` (`2px` `#313244` border)
  - Popup container: `22px` (`2px` `#45475a` border)
  - Buttons / workspace pills / Rofi window: `16–18px`
  - Top Polybar: `height = 40pt`, `radius = 16`, `border-size = 8pt` transparent outer margin (`~73px` top strut)
  - `bspwm`: `window_gap = 12`, `border_width = 2`
- **Transparency & `picom`:**
  - Keep `picom` on `backend = "xrender"`, `shadow = false`, `fading = false`, `vsync = true` for Mali/Termux:X11 performance.
  - Exclude `window_type = 'dock'`, `'desktop'`, and `fullscreen` from `picom` corner rounding (`corner-radius = 0`) so Polybar and 32-bit ARGB Eww docks render their own corners cleanly.
  - Always ensure `picom` is running before `eww daemon` starts so GTK3 acquires a `depth=32` RGBA visual instead of `depth=24`.

## 4. Bar Responsibilities & Spatial Separation

- **Top bar (Polybar) = read-only statusbar:**
  - Left: active window title (`xwindow`, truncated at 60 chars)
  - Right: `cpu`, `memory` (`%gb_used% (%percentage_used%%)`), `battery`, `date`
  - **Do not** place workspace lists, launchers, or interactive click menus on the top bar.
- **Left dock (Eww) = touch control surface:**
  - Anchored `top left` at `x=0px, y=80px`, `width=128px`, `height=94%`, reserving `128px` left padding (`bspwm` struts + `bspc config left_padding 128`).
  - Top-to-bottom grouping separated by `60×2px` `#45475a` dividers:
    1. **Launchers:** App drawer (`rofi -show drun`), Terminal (`xfce4-terminal`), Window switcher (`rofi -show window`)
    2. **Workspaces `1`–`6` & Layout:** Live `bspc subscribe report` state (`focused` blue pill, `occupied` surface pill + `8px` blue dot, `empty` transparent), followed by Monocle/Tiled toggle (`M`/`T`)
    3. **Spacer** (`:vexpand true`)
    4. **Window actions:** Float toggle, Fullscreen toggle, Close window
    5. **Audio:** `+`, Mute/`%` badge, `-` (instant `eww update` on tap)
    6. **Session toggle:** Opens `330×330` `session_menu` popup at `x=140px` bottom-left (**Reload Bars**, **Restart WM**, **Exit X11**)
- **Inactive fallback:** Leave `~/.config/quickshell/` generation in `configure.py` intact, but keep `bspwmrc` launching `eww`.

## 5. Tablet & Touch Interaction Rules

- **No right-click or hover dependencies:** Every control must trigger on a single left-click/tap. Never use right-click bindings, hover-to-reveal menus, or keyboard-only actions for UI chrome.
- **No sticky `:hover` visuals:** Style `:active` press feedback only (`#89b4fa` background + `#1e1e2e` foreground); leave `:hover` unstyled so simulated touchscreen taps don't leave buttons highlighted.
- **Enlarged invisible hitboxes:** Keep visible pills `92×50–66px` inside `128px`-wide edge-to-edge transparent `button` containers (using `(overlay)` in Eww so `.dock-bg` sits inset at `x=12..128` while hitboxes reach `x=0`) with split-gap vertical padding (`6–7px` top/bottom, `spacing: 0`) so there are zero dead pixels between controls.
- **Cursor coherence:** Use the `TouchDot-Mocha` (`32px`) translucent frosted circle Xcursor (`~/.icons/TouchDot-Mocha`, `xsetroot -cursor_name left_ptr`) alongside `hide-cursor.py` (`XFixesHideCursor` after tap release and `0.6s` idle).

## 6. Termux / Android Runtime Constraints

- **SELinux `/proc` & `/sys` limits:** `/proc/stat`, `/proc/loadavg`, `/proc/uptime`, `/sys/class/power_supply`, `/sys/class/net`, and `/sys/class/thermal` return `Permission denied`. Never enable Polybar's `internal/cpu`, `internal/battery`, or `internal/temperature`:
  - Read CPU via readable `/proc/<pid>/stat` (`cpu.py`, `tail = true`).
  - Read battery via `timeout 4 termux-battery-status` (`battery.sh`).
  - Read RAM via `/proc/meminfo` (`internal/memory`).
- **Hotkeys (`sxhkd 0.6.3`):** Never combine `{alt,super}` with a second `{...}` brace group when the command also expands `{...}`—keep separate `alt + ...` and `super + ...` stanzas.
- **Safe X11 verification:** Test GUI changes headlessly on `DISPLAY=:9` (`termux-x11 :9` without `am start`) and kill all `:9` processes/sockets afterward so the foreground Android screen is never hijacked.
